# Operational dashboard release — 2026-10-29

The home page opens on operations: active work, review, overdue and unassigned tasks, the original Woss mascot, a larger status chart, and weekly/monthly planning. Business indicators remain available in a separate view. Cards use the existing Antuario palette, rounded corners and shadows. Motion can be paused and respects reduced-motion preferences.

Accounts and Production edit the same task IDs. Dates retain America/Mexico_City semantics, including undated tasks and proposed/confirmed/follow-up intent. Reviewer assignment and client dependencies are explicit; historical records are not classified automatically. Financial amounts start concealed.

This commit also records the deployed workspace modules that had previously been released from a local checkout without being committed. Existing roles, account boundaries and communication behavior are preserved.

## Configuration

`WOSS_INSTRUCTIONS_JSON` is a server-only production secret containing the private instruction document (`markdown` and `updatedAt`). Its contents and historical financial fixtures are intentionally excluded from public Git. Local development can use the ignored `lib/private/woss-instructions.json`. Missing configuration is shown explicitly rather than replaced with an incomplete mandate. Account commercial terms come from the database, not hardcoded amounts.

Only the additive `20261028201618_operational_calendar_date_kind.sql` schema change belongs to this release. It was applied independently after checking the existing schema. Older migrations are historical source: do not blindly replay them or private seeds against production.

## Validation

The full local regression suite passed (170 tests before the final private-document test was added). All 11 affected regression tests passed after the configuration change; TypeScript and the production build passed. Desktop, compact laptop and mobile were checked with synthetic data: filters, month/week switch, shared task editor, motion pause/resume, reduced motion and financial privacy. Private local evidence is not published to this repository.

Production URL: https://dashboard.antuario.mx. The exact released commit, deployment and authenticated smoke-test result are recorded in the original operational tasks after publication.
